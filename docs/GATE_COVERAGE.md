# Gate Coverage Matrix

| Gate | Core decision | Major synthetic evidence |
|---|---|---|
| General | commit resources / next phase | business case, budget, portfolio, action register, benefits plan |
| IT | standards + run operability | CMDB, catalog, licence, lifecycle, capacity, RACI, ITSM, waiver |
| Architecture | information-system coherence | HLD, LLD, APIs, flows, data, IP, ADRs, debt, performance |
| Security Architecture | cyber-risk acceptability | Azure inventory, IAM, WAF, firewall, NSG, Key Vault, SIEM, Defender, vuln/pentest |
| Tech Readiness | production aptitude | load, CI, backup, restore, failover, SLO/SLI, rollback, runbook |
| Procurement | supplier/sourcing commitment | RFP, competing offers, scoring, TCO, due diligence |
| Legal | contractual conformity | MSA, DPA, SLA, insurance, authority matrix, playbook, negotiation log |
| Compliance | regulatory/standards conformity | inventory, RoPA, DPIA, mapping, retention, accessibility, controls, AI assessment |
