# Response to methodological and scope critiques

The second manuscript is now **DGF-Bench: Rule Application and Evidence Reliability in Synthetic Governance Reviews** (19 pages). The 59-page first paper remains unchanged. The second paper's stable PDF filename is retained for existing links.

| Criticism | Completed response | Remaining boundary |
|---|---|---|
| Public rules and facts already solve the task | Executed deterministic control: 1,700/1,700 strict gates, 300/300 routes; conclusion explicitly states no incremental LLM advantage in this condition | Unstructured extraction and policy formalization remain unmeasured |
| Baseline has unlimited quotation length | Public algorithm and no-output-token-limit asymmetry described; control labeled a sufficiency test | Equal-resource end-to-end comparison remains needed |
| Gemini-only audit could distort the comparison | Exhaustive audit of all 690 evidence-failed gates across the three models; declared lexical-or-structural sensitivity rates at gate and route level | Not semantic entailment, premise completeness, or independent expert adjudication |
| Strict gate/route gap overinterpreted | Original endpoint retained; relaxed Gemini routes 284/299, Luna 144/300, DeepSeek 85/300 reported separately | Post-hoc result, not a replacement primary endpoint |
| Missing error decomposition | Full decision matrices, Procurement rule-level diagnostics, and restrictive/nonrestrictive error counts | Parser failure does not imply a false claim |
| Dynamic reference makes 100% ambiguous | Initial and effective agreements both reported; Gemini's 141 differences split into 139 local approvals and two upstream-derived General outcomes | Permitted approvals remain part of the declared task |
| Cheap removal of facts not attempted | Executed offline preflight: 26 identical Word-document texts can require different Procurement answers; frozen scorer requires the removed snapshot ID | A common evidence contract and sufficient source records are needed before paid ablations |
| One trajectory per original model-case pair | 135 completed new runs, 765 gates, all outcomes and failed attempts retained; stratified case-cluster intervals | Only 15 existing dossiers; no independent dataset replication |
| Workforce/FDE thesis exceeds evidence | Empirical title, shorter abstract, brief deployment/workforce discussion; extensive theory and scenarios retained in first paper | No measured staffing effect or enrolled cohort |
| Closest research missing | Added rule following, legal reasoning, evidence attribution, process compliance, cost-aware evaluation, automation-bias references | Cross-benchmark headline rates are not compared |
| Editorial revision language and hard-to-find URL | Manuscript describes final scientific contribution; visible repository URL included | This response document retains editorial history outside the PDF |
