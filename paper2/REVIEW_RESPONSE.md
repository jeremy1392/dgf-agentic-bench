# Changes in the second manuscript

This document records editorial changes and the additional observations still needed. Neither a new benchmark collection nor an enterprise study was conducted for this revision. The 59-page first paper is preserved separately.

| Criticism | Change in this manuscript | Remaining empirical work |
|---|---|---|
| Universal “law” exceeds the evidence | Conditional task-substitution hypothesis; measured performance, deployment hypothesis, and workforce projection explicitly separated | Operational quality and human-work measurement |
| Three papers in one | Benchmark as the central contribution; one compact labor account; one sensitivity illustration; detailed derivation in appendix | None for the editorial change |
| FDE title without concrete implementation | Specification of policy contracts, evidence connectors, authority controls, shared case state, recovery, and labor accounting | Evaluate actual deployments and implementation comparisons |
| Explicit rules and REVIEW_FACTS make disposition prediction easy | Foreground scaffolding and Gemini's near-saturated disposition score; require a deterministic rules comparator | Run the comparator and scaffold-removal conditions on held-out cases |
| Evidence metric is lexical | Separate disposition correctness, evidence-only failures, and strict route success; retain original scores | Independent semantic adjudication with a frozen rubric |
| Field-order example overinterpreted | Explicitly state that one example does not establish that most Gemini failures are harmless | Label failure types and sample passing evidence |
| One trajectory and only three endpoints | State the scope of confidence intervals and endpoint selection; design repeats and broader comparisons | Collect repeated trajectories and additional models |
| No human baseline | Specify matched information, unaided/agent/assisted arms, qualified reviewers, counterbalancing, and timing | Recruit participants, register protocol, collect and adjudicate results |
| Scenario arithmetic treated as evidence | Label labor equation an accounting identity; use one explicit assumption table | Measure real workload parameters |
| Algebraically identical H4 comparator | No claim of predictive superiority over the same identity with consistent inputs | Compare empirically meaningful implementations, not equivalent arithmetic |
| Expired baseline window | Historical records required for original 2026–2033 test; a new prospective baseline gets a new dated hypothesis | Enroll eligible organizations and audit baseline completeness |
| Unpublished practitioner source | Public code, route definitions, documents, and rules serve as the inspectable task specification | Independent professional validation of those rules |
| Repetitive qualifications | Central claim table and dedicated interpretation/validation sections | None for the editorial change |

The paper continues to argue that review automation could replace human work and reduce required DGF staffing. It does not present an 80% staffing effect as measured by the benchmark. Required FTE, allocated staffing, headcount, and hiring remain separate reported outcomes.
