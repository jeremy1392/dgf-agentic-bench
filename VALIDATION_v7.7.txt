DGF-Bench v7.7 validation
========================
Date: 2026-09-22

Primary change
--------------
Independent (model × DGF case) jobs can now execute concurrently.
Default concurrency:
- --workers 6
- --max-workers-per-model 0 (auto = ceil(workers / active_models))
- --job-budget-reserve-usd 0.50

Scientific constraint preserved
-------------------------------
Gates inside one DGF route remain sequential in handoff_mode=agent.
Only independent model×case jobs are concurrent. Therefore downstream gates still receive
that model's actual upstream handoff in route order.

Concurrency / reliability additions
-----------------------------------
- ThreadPoolExecutor-based job execution.
- Balanced round-robin queue order retained.
- Thread-safe cost ledger.
- Per-in-flight-job budget reservation before paid work starts.
- Per-model concurrency cap.
- OpenRouter 429/5xx/network retry counters recorded per case.
- Gate-level checkpoint resume for interrupted cases.
- Previous failed attempts are retained instead of overwritten.
- Previous partial/failed API costs stay in resumed experiment accounting.
- OK and AGENT_FAILURE cases resume as final; INFRA_ERROR and BUDGET_STOP are retryable.
- benchmark_run_stats.json records elapsed time, concurrency and budget state.
